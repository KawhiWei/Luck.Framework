# 2.0.14 更新记录

## 重要变更

- 所有运行时类库、单元测试和样例统一升级到 `net10.0`。从本版本开始不再发布 `net6.0`、`net7.0`、`net8.0` 和 `net9.0` 资产。
- 删除所有按目标框架设置的旧版本覆盖，仓库中的直接 NuGet 依赖统一使用 2026-08-25 可用的最新稳定版本。
- MySQL EF Core 提供程序从 `Pomelo.EntityFrameworkCore.MySql` 迁移到 Oracle `MySql.EntityFrameworkCore` 10.0.9，以与 EF Core 10 保持一致。使用方应复核 MySQL/MariaDB 兼容性、SQL 生成结果和许可证要求。
- 类库包版本统一更新为 `2.0.14`。

## 文档

- 所有类库 README 的安装版本更新为 2.0.14，并统一说明 `net10.0` 支持基线。
- 修正 ClickHouse、MongoDB、EF Core、Serilog 与 Source Generator 文档中的过期依赖版本和目标框架说明。
- 根 README 增加当前版本记录入口，并更新 MySQL 提供程序说明。

## 升级注意事项

- 应用需要安装 .NET 10 SDK 和运行时。
- Oracle MySQL 提供程序的 API、MariaDB 支持范围和许可证不同于 Pomelo；升级前需要执行真实数据库回归测试。
- 源生成器继续以 `netstandard2.0` 发布，但编译依赖升级到 Roslyn 5.9；仓库通过 Microsoft.Net.Compilers.Toolset 5.9 验证项目编译与 analyzer 加载。当前测试模型没有匹配类，不覆盖注册源码实际生成。
- 数据库、RabbitMQ、Redis、MongoDB 和 ClickHouse 的集成验证仍需要对应外部服务。
