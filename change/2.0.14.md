# 2.0.14 更新记录

## 重要变更

- 继续发布 `net6.0`、`net7.0`、`net8.0`、`net9.0` 和 `net10.0` 资产，不缩减既有目标框架支持。
- 不受 TFM 限制的直接 NuGet 依赖升级到 2026-08-25 可用的最新稳定版；EF Core、Microsoft.Extensions、Serilog.AspNetCore 和 OpenTelemetry 按目标框架使用最新兼容稳定版。
- MySQL 在 net6-net9 继续使用 Pomelo，在 net10 使用 Oracle `MySql.EntityFrameworkCore` 10.0.9，以同时满足多目标支持和 EF Core 10 兼容性。
- 类库包版本统一更新为 `2.0.14`。

## 文档

- 所有类库 README 的安装版本更新为 2.0.14，并保留 net6-net10 多目标支持说明。
- 修正 ClickHouse、MongoDB、EF Core、Serilog 与 Source Generator 文档中的过期依赖版本和目标框架说明。
- 根 README 增加当前版本记录入口，并更新 MySQL 提供程序说明。

## 升级注意事项

- 构建全部目标框架需要对应的 .NET 6、7、8、9、10 targeting packs；消费方只需安装自身目标框架对应的 SDK 和运行时。
- net10 使用的 Oracle MySQL provider 与 net6-net9 的 Pomelo 在 API、MariaDB 支持范围和许可证上存在差异；升级前需要执行真实数据库回归测试。
- 源生成器继续以 `netstandard2.0` 发布，但编译依赖升级到 Roslyn 5.9；仓库通过 Microsoft.Net.Compilers.Toolset 5.9 验证项目编译与 analyzer 加载。当前测试模型没有匹配类，不覆盖注册源码实际生成。
- 数据库、RabbitMQ、Redis、MongoDB 和 ClickHouse 的集成验证仍需要对应外部服务。
