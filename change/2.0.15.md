# 2.0.15 更新记录

日期：2026-08-25

## 重大变更

- 所有运行时类库、样例项目和单元测试项目仅目标为 `net10.0`。`net6.0`、`net7.0`、`net8.0` 与 `net9.0` 资产不再构建或发布。
- 删除旧目标框架专用的 NuGet 版本覆盖、EF Core 兼容矩阵和 `Pomelo.EntityFrameworkCore.MySql` 分支。
- `Luck.EntityFrameworkCore.MySQL` 仅使用 `MySql.EntityFrameworkCore`（Oracle Connector/NET）作为 EF Core 10 提供程序。
- 类库包版本更新为 `2.0.15`。

## 升级影响

- 使用 `net6.0` 至 `net9.0` 的应用必须先升级到 .NET 10，才能引用 2.0.15 及后续运行时包。
- MySQL 使用者应验证 Oracle Connector/NET 与其 MySQL/MariaDB 版本、连接配置和许可证要求是否匹配。
- NuGet 源在本次验证环境中无法解析域名；因此版本表基于前一版本已完成的 2026-08-25 稳定包基线。恢复结果会使用本机 NuGet 缓存验证引用可用性。

## 验证

```bash
dotnet restore Luck.sln
dotnet build Luck.sln --no-restore
dotnet test test/Luck.UnitTest/Luck.UnitTest.csproj --no-build
```

完整构建已通过。集成测试需要 ClickHouse（`127.0.0.1:9000`）和 MongoDB（`localhost:27017`）；未启动这些服务时，相关测试会因连接失败而无法完成。
